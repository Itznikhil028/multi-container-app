# Multi Container Application

Project demonstrating multiple containers working together using Docker Compose.

## Topics Covered

* Docker Compose
* Multi-container architecture
* Service communication
* Container orchestration basics

## Run

```bash
docker compose up -d
```

## Commands Practiced

```bash
docker compose ps
docker compose down
docker compose logs
```

## Learning Outcome

Learned how multiple services communicate and run together.

Built during Cloud + DevOps learning.
